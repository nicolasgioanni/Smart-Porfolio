# Experience and Research evidence

Owns [Experience](../../src/components/portfolio/experience/ExperienceShowcase.tsx), [Research](../../src/components/portfolio/research/ResearchShowcase.tsx), and the shared [detail disclosure](../../src/components/portfolio/shared/DetailDisclosureList.tsx). Research media follows [graphical-abstract resolution](../../src/lib/content/researchGraphicalAbstracts.ts) and [video resolution](../../src/lib/content/researchVideos.ts) into [graphical previews](../../src/components/portfolio/research/ResearchGraphicalAbstractPreview.tsx) and [video previews](../../src/components/portfolio/research/ResearchVideoPreview.tsx); components do not bypass those resolvers. Reuse [detail selection](../../src/lib/content/selectDetailContent.ts); preserve one active evidence row and static media before enhancement.

Read [detail selection](../../docs/content/CONTENT_MAPPING.md#detail-selection) and [evidence accessibility](../../docs/design/ACCESSIBILITY.md#research-and-experience-details). Validate with [Research coverage](../../src/components/portfolio/research/ResearchShowcase.test.tsx), [video-preview coverage](../../src/components/portfolio/research/ResearchVideoPreview.test.tsx), and `npm run test -- src/components/portfolio/research/ResearchShowcase.test.tsx src/components/portfolio/research/ResearchVideoPreview.test.tsx`.

Run `npm run test:e2e:research` for media, focus, or viewport changes. Run `npm run test:e2e:research:webkit` after installing WebKit for mobile captions or fullscreen video; it supplements Chromium coverage. Broaden to `npm run test:priority` when disclosure, resolution, or shared evidence UI changes. Route dialogs to the modal card and loader geometry to the skeleton card.
