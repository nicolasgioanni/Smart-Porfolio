# tests

Cross-domain browser and quality test harness. Select existing browser or quality coverage that observes the behavior; preserve strict assertions.

Start at `playwright.config.ts` and inspect `tests/e2e/accessibility.spec.ts`. Read the [portfolio-validation](../skills/portfolio-validation/SKILL.md) and [authority](../../docs/quality/TESTING.md#command-matrix) for this contract. Run `npm run test:e2e:accessibility` as applicable.

Consumers: ci. CI assignment changes require CI evidence guidance; loader regressions require the skeleton specialist.
